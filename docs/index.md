# Главная страница

<img src="/images/welcome_banner.png" alt="Добро пожаловать" class="banner-img" />

**MAESTROS PROJECT** — Military RP проект в GoreBox, объединяющий тактический геймплей, дисциплину и продуманную ролевую атмосферу.

::: info С чего начать новичку:
1. Изучите [**Правила ЧЕЧНЯ РП**](/chechnya-rp/rules), чтобы не получить наказание с первых минут.
2. Выберите сторону в разделе [**Фракции и подразделения**](#фракции-и-подразделения-выбор-стороны) (**ВС РФ** или **ЧРИ**), откройте её **Архитектуру** и посмотрите форму и задачи своей роли.
3. Ознакомьтесь с [**Системой званий и заслуг**](/chechnya-rp/ranks), чтобы получать повышения через [**Discord**](https://discord.gg/jDbRN3Kgg).
:::
