# Система званий и заслуг

У каждой стороны конфликта своя система карьерного роста: у **ВС РФ** — учёт заслуг через бота и рапорты, у **ЧРИ** — выдвижение командиром и решение Штаба.

***

## ВС РФ

Повышение по службе происходит за счёт **заслуг (медалей)**, которые начисляются в Discord через бота (**UnbelievaBoat** / `!balance`) по отчётам игроков.

### Условия получения заслуг

#### Для всех бойцов
* **Участие на запуске** — `1` заслуга
* **Обычное убийство** — `1` заслуга
* **РП убийство** — `5` заслуг
* **Взятие в плен** — `8` заслуг
* **Обмен пленного** — `5` заслуг
* **Уничтожение техники** — `2` заслуги

#### Для офицеров
* **Успешный проведённый набег** — `2` заслуги
* **Обговорённый план в строю** *(полный скриншот строя и чата)* — `1` заслуга
* **Возвращение техники на базу в целости после набега** — `1` заслуга
* **Проведённое обучение новичков** — `1` заслуга *(за каждого бойца)*
* **Проведённое обучение специальности** — `1` заслуга *(за каждого бойца)*

### Форма отправки отчёта на заслуги
Отправляется в соответствующий канал отчётов в Discord:
1. **Медиа-материал** *(скриншот или откат)*
2. **Краткое объяснение**, что именно вы сделали
3. **Новым сообщением** под отчётом написать: `!balance`

### Форма подачи заявления на повышение звания
Когда накопилось нужное количество заслуг, подайте рапорт в канал повышений в Discord:
1. Скопируйте и заполните шаблон:
   `Я "РП-ФИО" ознакомлен с #🏆звания и прошу @Офицер рассмотреть моё заявление на повышение до звания "звание"`
2. **Следующим сообщением** напишите: `!balance`

::: info
**Пример:**
`Я "Иванов Иван Иванович" ознакомлен с #🏆звания и прошу @Офицер рассмотреть моё заявление на повышение до звания "Ефрейтор"`
Следующее сообщение: `!balance`
:::

## ЧРИ (Боевики)

Повышают **за заслуги в бою**, а не за выслугу. Командир предлагает, Штаб утверждает.

### Иерархия званий ЧРИ

| Категория | Тег | Звание / Статус |
| :--- | :--- | :--- |
| **Рядовой состав** | `БЦ.` | Боец |
| | `СТ.ГР.` | Старший группы |
| **Командиры звеньев** | `КМ.ГР.` | Командир группы |
| | `НАИБ` | Наиб *(заместитель командира отряда)* |
| **Командование отрядов** | `ПК.` | Полевой командир *(командир отряда)* |
| **Высшее руководство** | `АМИР` | Амир сектора |
| | `НШ.` | Начальник штаба / Член Совета командиров |

`Боец` → `Старший группы` → `Командир группы` → `Наиб` → `Командир отряда` → `Амир сектора / Начальник штаба`

### Как получить повышение
1. Командир подаёт рапорт в канале `#рапорты`: ник, должность, за что *(операции, засады)*, кто рекомендует.
2. До **Старшего группы** решение принимает командир отряда. Выше — решает **Штаб** *(голосование ✅/❌ в треде)*.
3. Модератор меняет роль и публикует запись в `#указы`.

### Награды
Награды выдаются отдельными ролями-значками с записью в `#награды`.
Высшая награда — **орден «Честь Нации»**.

### Разжалование
::: danger
Приказом **Штаба** или **ДГБ** за слив координат, мародёрство или срыв приказа звание и награды снимаются.
:::
