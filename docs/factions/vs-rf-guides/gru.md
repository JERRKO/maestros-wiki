# Спецназ ГРУ (Войсковая разведка)

**Кто это:** Элитное разведподразделение для скрытной работы за пределами базы.

## Форма и экипировка
* **Форма:** Маскировочный камуфляж (горка / маскхалат), разгрузка, балаклава, без ярких демаскирующих элементов.
* **Вооружение:** Бесшумное или дальнобойное оружие (ВСС, АС «Вал», СВД, АК с глушителем), мины/взрывчатка (для сапёра).

## Что делать на службе
1. Проводить разведку маршрутов перед выходом колонн.
2. Искать схроны, лагеря и пути снабжения боевиков.
3. Устраивать засады, ликвидировать полевых командиров и брать «языков» (пленных) для ФСБ.
4. Работать тихо и слаженно под руководством КРГ.
